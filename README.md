# Boursa AI

An educational Iranian market analytics dashboard and paper-trading simulator. This project is for learning and research only. It does not provide investment advice, execute orders, or connect to brokerage accounts.

## Planned stack
- Next.js, TypeScript, Tailwind CSS
- PostgreSQL (Neon) for watchlists and paper portfolios
- Clearly labelled sample/historical market data until a verified, permitted data source is configured

## Safety and data integrity
- No live brokerage credentials or order execution.
- Sample data must be labelled as simulated and never presented as live quotes.
- Any market-data provider must be reviewed for licensing, terms, and reliability before use.

## Development

```bash
npm install
npm run dev
```
